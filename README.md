# freestyle

Сайт Кингсайза: индивидуальные онлайн-разборы и тренировки для опытных фристайлеров.

## Где править

- `index.html` — тексты, цены и ссылки.
- `styles.css` — оформление и адаптивная вёрстка.
- `assets/` — фотографии, локальные шрифты и лицензии.

Статический сайт без сборщика, зависимостей и JavaScript.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8131 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8131/.

## GitHub Pages

**Источник продакшена:** ветка **`main`**, каталог **`/` (root)**.

Settings → Pages → Build and deployment → Branch: **main** / **/(root)**.

Старые редакции сохранены в тегах (`v0.6.0` … `v0.8.0`) и ветках `editorial-v0.7`, `editorial-v0.8`.
