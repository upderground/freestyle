# freestyle

Сайт Кингсайза: индивидуальные онлайн-разборы и тренировки для опытных фристайлеров.

## Где править

- `index.html` — тексты, цены и ссылки.
- `styles.css` — оформление и адаптивная вёрстка.
- `assets/` — фотографии, локальные шрифты и лицензии.

Статический сайт без сборщика, зависимостей и JavaScript.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8131 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8131/.

## Публикация позже

Сейчас репозиторий приватный. GitHub Pages и автоматический деплой не настроены.
Когда сайт будет готов, на GitHub Free можно сделать этот репозиторий публичным
и включить Pages: **Deploy from a branch → main → / (root)**.
При открытии репозитория станет доступна и история последующих правок.
